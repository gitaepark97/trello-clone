# list Specification

## Purpose

리스트(List)는 보드 안에서 카드를 단계별로 분류하는 컬럼이며, 특정 보드에 속하고 보드 내에서 고유한 순서를 가진다.

## Requirements

### Requirement: 리스트 생성
시스템은 특정 보드에 속하는 리스트를 생성해야 한다(SHALL). 제목은 필수이며, 새로 생성된 리스트는 해당 보드의 리스트 순서상 가장 마지막 위치에 추가된다.

#### Scenario: 보드에 리스트 정상 생성
- **WHEN** 사용자가 존재하는 보드에 제목을 포함한 리스트 생성 요청을 보내면
- **THEN** 시스템은 새 리스트를 생성하고 해당 보드의 마지막 순서로 배치한다

#### Scenario: 존재하지 않는 보드에 리스트 생성 시도
- **WHEN** 사용자가 존재하지 않는 보드 식별자로 리스트 생성을 요청하면
- **THEN** 시스템은 찾을 수 없음 오류를 반환한다

#### Scenario: 제목 없이 리스트 생성 시도
- **WHEN** 사용자가 제목 없이(또는 빈 문자열로) 리스트 생성을 요청하면
- **THEN** 시스템은 요청을 거부하고 유효성 오류를 반환한다

### Requirement: 보드별 리스트 목록 조회
시스템은 특정 보드에 속한 리스트 목록을 순서(position)에 따라 정렬하여 조회할 수 있어야 한다(SHALL).

#### Scenario: 순서대로 리스트 목록 조회
- **WHEN** 사용자가 특정 보드의 리스트 목록 조회를 요청하면
- **THEN** 시스템은 해당 보드에 속한 삭제되지 않은 리스트를 순서(position) 오름차순으로 반환한다

### Requirement: 리스트 수정
시스템은 리스트의 제목을 수정할 수 있어야 한다(SHALL).

#### Scenario: 리스트 제목 정상 수정
- **WHEN** 사용자가 존재하는 리스트의 제목 변경을 요청하면
- **THEN** 시스템은 해당 리스트 정보를 갱신하고 변경된 결과를 반환한다

#### Scenario: 존재하지 않는 리스트 수정 시도
- **WHEN** 사용자가 존재하지 않는 리스트 식별자로 수정을 요청하면
- **THEN** 시스템은 찾을 수 없음 오류를 반환한다

### Requirement: 리스트 삭제
시스템은 리스트를 삭제할 수 있어야 하며(SHALL), 리스트가 삭제되면 해당 리스트에 속한 모든 카드도 함께 삭제되어야 한다(MUST).

#### Scenario: 리스트 삭제 시 하위 카드 함께 삭제
- **WHEN** 사용자가 카드를 포함한 리스트의 삭제를 요청하면
- **THEN** 시스템은 해당 리스트와 그에 속한 모든 카드를 삭제한다

#### Scenario: 존재하지 않는 리스트 삭제 시도
- **WHEN** 사용자가 존재하지 않는 리스트 식별자로 삭제를 요청하면
- **THEN** 시스템은 찾을 수 없음 오류를 반환한다

### Requirement: 리스트 순서 변경
시스템은 같은 보드 내에서 리스트의 순서를 변경할 수 있어야 한다(SHALL). 순서를 변경하면 해당 보드에 속한 다른 리스트들의 순서도 일관되게 조정되어야 한다(MUST).

#### Scenario: 같은 보드 내에서 리스트 순서 정상 변경
- **WHEN** 사용자가 리스트를 같은 보드 내의 새로운 위치로 이동 요청하면
- **THEN** 시스템은 해당 리스트의 순서를 갱신하고, 영향을 받는 다른 리스트들의 순서도 일관되게 재조정한다

#### Scenario: 존재하지 않는 리스트의 순서 변경 시도
- **WHEN** 사용자가 존재하지 않는 리스트 식별자로 순서 변경을 요청하면
- **THEN** 시스템은 찾을 수 없음 오류를 반환한다
