## Purpose

카드(Card)는 실제 작업 단위를 나타내며, 특정 리스트에 속하고 리스트 내에서 순서를 가지며 다른 리스트로 이동할 수 있다.

## ADDED Requirements

### Requirement: 카드 생성
시스템은 특정 리스트에 속하는 카드를 생성해야 한다(SHALL). 제목은 필수이며 설명(description)은 선택 항목이다. 새로 생성된 카드는 해당 리스트의 카드 순서상 가장 마지막 위치에 추가된다.

#### Scenario: 리스트에 카드 정상 생성
- **WHEN** 사용자가 존재하는 리스트에 제목을 포함한 카드 생성 요청을 보내면
- **THEN** 시스템은 새 카드를 생성하고 해당 리스트의 마지막 순서로 배치한다

#### Scenario: 존재하지 않는 리스트에 카드 생성 시도
- **WHEN** 사용자가 존재하지 않는 리스트 식별자로 카드 생성을 요청하면
- **THEN** 시스템은 찾을 수 없음 오류를 반환한다

#### Scenario: 제목 없이 카드 생성 시도
- **WHEN** 사용자가 제목 없이(또는 빈 문자열로) 카드 생성을 요청하면
- **THEN** 시스템은 요청을 거부하고 유효성 오류를 반환한다

### Requirement: 리스트별 카드 목록 조회
시스템은 특정 리스트에 속한 카드 목록을 순서(position)에 따라 정렬하여 조회할 수 있어야 한다(SHALL).

#### Scenario: 순서대로 카드 목록 조회
- **WHEN** 사용자가 특정 리스트의 카드 목록 조회를 요청하면
- **THEN** 시스템은 해당 리스트에 속한 삭제되지 않은 카드를 순서(position) 오름차순으로 반환한다

### Requirement: 카드 단건 조회
시스템은 식별자로 특정 카드를 조회할 수 있어야 한다(SHALL).

#### Scenario: 존재하지 않는 카드 조회
- **WHEN** 사용자가 존재하지 않는 카드 식별자로 조회를 요청하면
- **THEN** 시스템은 찾을 수 없음 오류를 반환한다

### Requirement: 카드 수정
시스템은 카드의 제목과 설명을 수정할 수 있어야 한다(SHALL).

#### Scenario: 카드 제목/설명 정상 수정
- **WHEN** 사용자가 존재하는 카드에 대해 제목 또는 설명 변경을 요청하면
- **THEN** 시스템은 해당 카드 정보를 갱신하고 변경된 결과를 반환한다

#### Scenario: 존재하지 않는 카드 수정 시도
- **WHEN** 사용자가 존재하지 않는 카드 식별자로 수정을 요청하면
- **THEN** 시스템은 찾을 수 없음 오류를 반환한다

### Requirement: 카드 삭제
시스템은 카드를 삭제할 수 있어야 한다(SHALL).

#### Scenario: 카드 정상 삭제
- **WHEN** 사용자가 존재하는 카드의 삭제를 요청하면
- **THEN** 시스템은 해당 카드를 삭제한다

#### Scenario: 존재하지 않는 카드 삭제 시도
- **WHEN** 사용자가 존재하지 않는 카드 식별자로 삭제를 요청하면
- **THEN** 시스템은 찾을 수 없음 오류를 반환한다

### Requirement: 같은 리스트 내 카드 순서 변경
시스템은 같은 리스트 내에서 카드의 순서를 변경할 수 있어야 한다(SHALL). 순서를 변경하면 해당 리스트에 속한 다른 카드들의 순서도 일관되게 조정되어야 한다(MUST).

#### Scenario: 같은 리스트 내에서 카드 순서 정상 변경
- **WHEN** 사용자가 카드를 같은 리스트 내의 새로운 위치로 이동 요청하면
- **THEN** 시스템은 해당 카드의 순서를 갱신하고, 영향을 받는 다른 카드들의 순서도 일관되게 재조정한다

### Requirement: 카드를 다른 리스트로 이동
시스템은 카드를 다른 리스트의 특정 위치로 이동할 수 있어야 한다(SHALL). 이동이 발생하면 원본 리스트와 대상 리스트 양쪽의 카드 순서가 모두 일관되게 조정되어야 한다(MUST).

#### Scenario: 다른 리스트의 특정 위치로 카드 정상 이동
- **WHEN** 사용자가 카드를 다른 리스트의 특정 위치로 이동 요청하면
- **THEN** 시스템은 카드의 소속 리스트와 순서를 갱신하고, 원본 리스트와 대상 리스트에 남은 카드들의 순서를 모두 일관되게 재조정한다

#### Scenario: 존재하지 않는 대상 리스트로 이동 시도
- **WHEN** 사용자가 존재하지 않는 리스트 식별자를 대상으로 카드 이동을 요청하면
- **THEN** 시스템은 찾을 수 없음 오류를 반환한다
